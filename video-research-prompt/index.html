The setup guide

  1. 1

    Get API access in AnswerThePublic

    Your AnswerThePublic workspace needs API access, because that's what lets your AI connect to it. In AnswerThePublic, the page that connects AI tools shows tabs for Claude, Claude Code, ChatGPT and others, with these same steps.

  2. 2

    Connect it to Claude

    In Claude, open Customize, then Connectors. Click + Add, then Add custom connector. Name it AnswerThePublic, paste this address: https://atp-mcp.answerthepublic.com/mcp and click Continue. Keep the settings it finds, pick Sign in now, click Add and sign in to AnswerThePublic.

  3. 3

    Turn it on in your chat

    In a new chat, click the + button at the bottom left, open Connectors and switch AnswerThePublic on.

  4. 4

    Using Claude Code instead?

    Run this in your terminal: claude mcp add --transport http answerthepublic https://atp-mcp.answerthepublic.com/mcp and sign in to AnswerThePublic when it asks.

  5. 5

    Check it's connected

    Ask Claude: What can you look up in AnswerThePublic?

    Ready when Claude names AnswerThePublic's tools. You can remove the connection anytime from the Connected Apps tab in AnswerThePublic.
